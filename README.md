# Modulo Auth Backend

Backend de autenticación modular construido con Node.js y Express.

## Requisitos

- Node.js >= 18.x
- npm >= 9.x

## Instalación

```bash
git clone https://github.com/pipipe123/modulo_auth_backend.git
cd modulo_auth_backend
npm install
```

## Uso

```bash
# Desarrollo
npm run dev

# Producción
npm start
```

## Estructura del proyecto

```
src/
├── index.js          # Punto de entrada
├── config/           # Configuración y variables de entorno
├── routes/           # Definición de rutas
├── controllers/      # Lógica de controladores
├── middlewares/       # Middlewares personalizados
├── models/           # Modelos de datos
└── utils/            # Utilidades
```
